1. ADNI
ADNI itself is not primarily a DLB cohort, but recent work has extracted DLB-positive subjects from it using alpha-synuclein biomarkers. One study identified DLB-positive subjects from ADNI by using the seed amplification assay (SAA) performed by Amprion Clinical Laboratory, requiring that CSF immunoassay and FDG-PET imaging were conducted within one year of the SAA, resulting in 618 individuals, with DLB positivity determined by alpha-synuclein SAA results. So you can mine ADNI for a DLB subset via SAA + FDG-PET + MRI, but it's not a pre-packaged "DLB dataset" — you'd need to do the biomarker-based stratification yourself
