\begin{abstract}
Intestinal parasitic infections affect billions of people globally, yet diagnosis relies heavily on labor-intensive manual microscopy. This project proposes an automated system for the detection, classification, and instance segmentation of parasite eggs (e.g., \textit{Ascaris}, \textit{Trichuris}, \textit{Hookworm}) in stool samples using Mask R-CNN. Unlike standard object detection models (like YOLO) that only output bounding boxes, Mask R-CNN provides pixel-level segmentation masks. This capability is critical for separating overlapping eggs from fecal debris and extracting morphological features for accurate species classification. This report summarizes significant academic publications that inform the methodology, covering the transition from Faster R-CNN to modern segmentation approaches \cite{viet2019parasite, anantrasirichai2022icip}.
\end{abstract}
